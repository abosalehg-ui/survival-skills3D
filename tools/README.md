# أدوات الصيانة

سكربتات Node بلا اعتماديات، تعمل بـ `node <script>` من جذر المستودع.
جميعها مستدعاة من `.github/workflows/ci.yml` عدا `vendor-three.mjs` (يُشغَّل يدوياً عند الترقية).

| السكربت | الغرض |
|---|---|
| `vendor-three.mjs` | يجلب Three.js (النواة + الإغلاق التعدّيّ الكامل لكل الوحدات التي تستوردها اللعبة) إلى `assets/vendor/three` |
| `verify-vendor.mjs` | يعيد حساب SHA-384 لكل ملف مستضاف ويقارنه بالبايتات الرسمية للإصدار — يمنع تعديلاً محلياً على اعتمادية بحجم 1.4 ميغابايت أن يمرّ بصمت |
| `check-dom-ids.mjs` | يتحقق أن كل `getElementById` / `querySelector('#…')` في السكربت له عنصر فعلي في الـ HTML |

```bash
node tools/vendor-three.mjs 0.160.0 assets/vendor/three
node tools/verify-vendor.mjs 0.160.0 assets/vendor/three
node tools/check-dom-ids.mjs index.html
```

## ترقية Three.js — مهمة مؤجَّلة عن قصد

الإصدار المثبّت **r0.160.0** (ديسمبر ٢٠٢٣). أحدث إصدار وقت كتابة هذا الملف **r0.185.x**.

**الترقية لم تُنفَّذ في هذا العمل، وهذا قرار لا سهو.** السبب:

- **لا متصفح في بيئة التطوير** (قيد معلن في `CLAUDE.md`)، والقفزة ٢٥ إصداراً تمرّ على تغييرات
  كاسرة في مسار العرض بالذات: توقيع `SMAAPass`، وإعادة تنظيم `Pass`/`postprocessing`،
  وحذف واجهات إضاءة وترميز ألوان قديمة.
- **فشلها صامت**: `setupPostProcessing()` و`setupGeometryMerger()` و`setupCamelModel()` كلها
  ملفوفة بـ `try/catch` تتراجع إلى مسار بسيط. أي كسر في الترقية لن يُظهر خطأ ولن يُسقط الـ CI
  (`node --check` يفحص الصياغة فقط) — ستفقد اللعبة التوهج والتنعيم ودمج الهندسة **إلى الأبد**
  دون أن يلاحظ أحد.
- **الدافع الأمني انتفى**: كان مبرر الترقية الأساسي هو سلسلة التوريد، وقد عولج جذرياً باستضافة
  المكتبة محلياً وإسقاط الـ CDN من الـ CSP نهائياً. لا ثغرة معروفة مستغَلّة في r160 لمكتبة رسم
  تعمل في العميل — هذا **دَيْن اعتماديات، لا ثغرة**.

**كيف تُنفَّذ عند توفّر متصفح** (صارت عملية أمر واحد بعد الاستضافة المحلية):

```bash
node tools/vendor-three.mjs 0.185.1 assets/vendor/three
node tools/verify-vendor.mjs 0.185.1 assets/vendor/three
# ثم حدّث رقم الإصدار في .github/workflows/ci.yml
```

**ما يجب فحصه بصرياً بعدها** (لا يكفي أن تُقلع اللعبة):

1. التوهج (bloom) والتنعيم (SMAA) شغّالان — افتح `?debug=1` وتأكد أن `qual` ينتهي بـ `+pp`.
2. `batch` في نفس اللوحة يُظهر `قبل→بعد` بأرقام مختلفة (دمج الهندسة لم يُكسر).
3. الجمل يظهر كنموذج لا كشكل إجرائي (أي أن `GLTFLoader` ما زال يعمل).
4. ألوان المراحل الست وتعريض ACES كما هي (`outputColorSpace` / `toneMapping`).
5. الظلال تتبع السيارة ولا تختفي بعد ٦٠ متراً.
