# نموذج الجمل

هذا المجلد هو **الاستثناء الوحيد** المعتمد من مالك المشروع لقاعدة «لا أصول خارجية»
(انظر `CLAUDE.md`).

## الملف الحالي

`camel.glb` (947 كيلوبايت) — زوّدني به مالك المشروع (تنزيل أصلي 7.3 ميجابايت من
مصدر خارجي)، وقمتُ بمعالجته محلياً قبل إضافته:

- **تبسيط الهندسة**: 79,165 مثلثاً → 7,972 (أداة `@gltf-transform` + `meshoptimizer`؛
  عقبة صغيرة تُرى من بعيد وتُتخطّى بسرعة لا تحتاج تفصيلاً بجودة عارضة سينمائية).
- **حذف الهيكل العظمي والأنيميشن**: كانا يزيدان الحجم دون فائدة لأن نظام العقبات
  المتحركة الحالي يُحرّك المجموعة كاملة (لا يشغّل أنيميشن مشي) — إن رغبتَ لاحقاً
  بتفعيل أنيميشن حقيقي فهذا يتطلب تعديل كود التحميل لاستخدام `AnimationMixer`.
- **تصغير الخامات**: 1024×1024 → 512×512، وتحويل لـ JPEG حيث لا حاجة لقناة شفافية
  (خامة العين البلورية (`02EyeSurface`, BLEND) أُبقيت PNG لأنها تحتاج شفافية).
- **تحقّق**: `gltf-transform validate` → صفر أخطاء، صفر تحذيرات. لا يستخدم أي
  امتداد glTF يحتاج فك تشفير خاص (Draco/KTX2)، فالمُحمِّل الحالي (`GLTFLoader`
  الأساسي، بلا مكوّنات فك تشفير إضافية) يقرأه مباشرة.

## ⚠️ الترخيص — يحتاج تأكيدك

لم يصلني اسم المصدر الأصلي أو نص الترخيص صراحةً مع الملف. **قبل الدمج**، تأكّد
أن ترخيص النموذج الذي نزّلته يسمح بإعادة التوزيع في مستودع عام على GitHub
(معظم منصات النماذج الحرة مثل Sketchfab/Poly Pizza تتيح ذلك بترخيصي CC0 أو
CC-BY — لكن بعض الرخص "Standard/Editorial" تمنع إعادة التوزيع). إن كان الترخيص
**CC-BY** (يتطلب إسناداً)، أضِف سطر شكر باسم المصدر/المنشئ في قسم "المطوّر" أو
"المصادر" بـ `README.md` الرئيسي.

## كيف تعمل اللعبة مع الملف

`setupCamelModel()` في `index.html` يُحمِّله بشكل غير معطِّل عند بدء اللعبة،
يُحجّمه ويُوسّطه تلقائياً، ويستنسخه (مع مشاركة الهندسة/المواد) لكل جمل يظهر في
المرحلة. **الجمل الإجرائي يبقى احتياطياً دائماً** — إن غاب الملف أو فشل تحميله
(مثلاً حذفتَه لاحقاً) لا ينكسر أي مستوى، يظهر الجمل الإجرائي بدلاً منه بصمت.

## PWA / العمل دون اتصال

الملف مُدرَج في `service-worker.js` ضمن `LOCAL_OPTIONAL` (تخزين مؤقت أفضل-جهد،
مثل إضافات post-processing) — يُخزَّن عند أول زيارة متصلة بالإنترنت للعمل لاحقاً
دون اتصال؛ فشل التخزين المؤقت لا يُسقط تثبيت الـ Service Worker.
